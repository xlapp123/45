# Healing Pocket (治愈系小手机 PWA)

## 快速部署到 GitHub Pages 并安装到手机桌面

1. **新建 GitHub 仓库**：
   - 登录 GitHub，创建一个新的公开/私有仓库（例如 `healing-pocket`）。
2. **上传文件**：
   - 将本压缩包解压后的所有文件（`index.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`）直接上传到仓库的根目录。
3. **开启 GitHub Pages**：
   - 进入仓库的 **Settings** -> **Pages**。
   - 在 **Build and deployment** 下的 **Branch** 选择 `main`（或 `master`），根目录选择 `/ (root)`，点击 **Save**。
   - 等待 1~2 分钟，即可获得类似 `https://你的用户名.github.io/healing-pocket/` 的 HTTPS 地址。
4. **在手机 Chrome / Safari / Edge 中安装到桌面**：
   - **Android / Chrome**：在手机上打开该网站，点击浏览器右上角三点菜单 -> 选择 **“添加到主屏幕”** 或 **“安装应用”**。
   - **iOS / Safari**：点击底部中间的“分享”按钮 -> 滑动选择 **“添加到主屏幕”**。
   - 即可像原生独立 App 一样全屏无边框打开治愈小手机！
